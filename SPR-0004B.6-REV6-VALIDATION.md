# SPR-0004B.6 Rev.6 — Validation

## Build

Compile the required environments from their platform-specific directories.

ESP32-WROOM examples:

```bash
cd firmware/esp32-wroom
pio run -e esp32dev
pio run -e esp32dev-aws
```

LilyGO examples:

```bash
cd firmware/lilygo-t-a7670
pio run -e lilygo-t-a7670
pio run -e T-A7670X-AWS
```

## ESP32-WROOM functional test

1. Start onboarding.
2. At step 3, open Network configuration.
3. Confirm the complete configuration page opens.
4. Confirm **Back to onboarding** returns to `/wizard?step=3`.
5. Repeat for steps 4 and 5.
6. From one of these steps, change a harmless setting and select **Save & Reboot**.
7. Confirm the save page shows a manual return link.
8. After the reboot, confirm the browser attempts to resume the originating wizard step.
9. At step 6, open full Status.
10. Confirm **Back to onboarding** returns to step 6.
11. Complete onboarding and confirm the normal Status start behavior remains unchanged.

## LilyGO functional test

Repeat the same flow for steps 3–6 and confirm the normal dashboard remains unchanged after onboarding completion.

## Important network note

When WiFi credentials or the device IP are changed, the browser may be unable to reopen the old host automatically after reboot. The manual return link and the normal device URL remain available once the browser can reach the device again.
