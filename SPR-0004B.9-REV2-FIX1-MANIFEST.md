# SPR-0004B.9-REV2-FIX1 Manifest

## Purpose

Correct the remaining ESP32-visible REV1 version caused by a board-local shadow copy of `version.h`.

## Changed files

- `firmware/common/system/version.h`
- `firmware/esp32-wroom/src/common/system/version.h`

Both now report:

- AWS: `SPR-0004B.9-REV2-AWS`
- MQTT: `SPR-0004B.9-REV2-MQTT`

## Root cause

The ESP32 tree contains `firmware/esp32-wroom/src/common/system/version.h`, which takes precedence over the shared `firmware/common/system/version.h` during the ESP32 build. REV2 originally updated only the shared copy.
