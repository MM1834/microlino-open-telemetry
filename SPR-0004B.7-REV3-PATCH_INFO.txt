SPR-0004B.7 Rev.3 — ESP32 and LilyGO GPS State Model

This package supersedes the earlier SPR-0004B.7 GPS packages.

Fixed
-----
The ESP32 Arduino core defines DISABLED as a preprocessor macro. The previous
MotGpsState::DISABLED enum member therefore failed to compile on both ESP32-WROOM
and LilyGO builds.

The enum members now use collision-resistant names:

- GPS_DISABLED
- GPS_NOT_DETECTED
- GPS_DETECTED
- GPS_FIX

Both firmware families use the same shared MotGps state model.

LilyGO alignment
----------------
- Added LilyGO GPS started/detected/state wrapper functions.
- Wizard hardware detection now reads the live GPS state.
- Onboarding capability JSON now reports the runtime GPS capability and state.
- Existing LilyGO GPS status endpoint continues to return the shared MotGps JSON.

Not included
------------
- PlatformIO environment cleanup
- Removal of legacy firmware variants
- AWS onboarding page
- Final onboarding documentation
- Network Manager / AP policy

Installation
------------
Extract directly over the repository root and overwrite files.
