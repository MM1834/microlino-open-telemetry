# SPR-0004B.6 Integration

## Base

Apply to the tested SPR-0004B.5 Rev.3 source state.

```bash
patch -p1 < SPR-0004B.6.patch
```

## Behaviour

- A fresh device or Factory Reset opens `/wizard` from `/`.
- Existing configured devices upgraded from Rev.3 also start with onboarding incomplete because the new preference key does not yet exist. The user may complete or skip the assistant without losing configuration.
- `/config` remains the single configuration UI.
- `POST /api/onboarding/complete` stores completion.
- `POST /api/onboarding/restart` clears completion only; it does not clear device configuration.
- `GET /api/onboarding` returns the current state and board capabilities.

## Firmware version

Expected build versions:

- `SPR-0004B.6-MQTT`
- `SPR-0004B.6-AWS`
