# SPR-0004B.6 Validation

## Automated/static validation performed

- Patch generated against the supplied repository plus the applied Rev.3 patch.
- Modified C++ files passed basic brace-balance and known-regression checks.
- The ineffective LilyGO `setup;` statement is absent.
- Board identity is selected by build target.
- Both WebUIs register onboarding status, complete and restart routes.

A PlatformIO compiler was not available in the execution environment, so hardware builds and uploads must be performed by the integrator.

## ESP32-WROOM test matrix

1. Build `esp32dev` and `esp32dev-aws`.
2. Verify serial banner reports `esp32-wroom` and `SPR-0004B.6-*`.
3. Factory Reset and reboot.
4. Open `/`; wizard must appear.
5. Verify progress shows step 1 of 7.
6. Open `/api/onboarding`; expect WiFi=true, LTE=false, GPS=true, CAN channels=1.
7. Open configuration from wizard; save and reboot.
8. Mark onboarding complete; `/` must show normal status page.
9. POST `/api/onboarding/restart`; configuration must remain intact and `/wizard` must return.
10. Regression-test CAN, GPS, MQTT/AWS, ABRP, OTA and Factory Reset.

## LilyGO test matrix

1. Build `lilygo-t-a7670` and `T-A7670X-AWS`.
2. Verify serial banner reports `lilygo-t-a7670` and no stray setup output or crash.
3. Repeat onboarding flow.
4. `/api/onboarding` must report WiFi=true, LTE=true, GPS=true, CAN channels=1.
5. Regression-test modem boot, LTE, WiFi fallback, GPS, CAN, MQTT/AWS, ABRP and OTA.
