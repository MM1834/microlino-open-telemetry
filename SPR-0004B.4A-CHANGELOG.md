# SPR-0004B.4A Changelog

## Added
- Authentifizierte WebSocket API für das Dashboard.
- Verbindungs- und Subscription-Speicher in DynamoDB.
- `subscribe`- und `ping`-Protokoll mit `subscribed`- und `pong`-Antworten.
- Separater Live-Verbindungsstatus im Dashboard.
- Konfigurierbare Reconnect-Sequenz 5 / 15 / 60 / 120 / 300 Sekunden.
- 30-Sekunden-Heartbeat.

## Unchanged
- REST-Snapshot-Polling bleibt bei 5 Sekunden.
- StateIngest schreibt weiterhin nur nach DynamoDB.
- Firmware bleibt unverändert.
