# SPR-0004B.6 Rev.6 — Changelog

## Changed

### ESP32-WROOM

- Wizard steps 3, 4 and 5 open the existing complete configuration page with their originating wizard step.
- The configuration page displays **Back to onboarding** when opened from the wizard.
- The originating wizard route is carried through the Save form.
- After Save & Reboot, the browser attempts to resume the originating wizard step automatically.
- The save confirmation also provides a manual return link.
- The full Status page opened from validation provides a return link to wizard step 6.

### LilyGO T-A7670

- Equivalent return behavior was added for wizard steps 3, 4, 5 and 6.
- The complete LilyGO configuration page remains unchanged in scope.
- Save & Reboot preserves the originating wizard step.
- The normal dashboard opened from validation provides a return link to wizard step 6.

## Intentionally unchanged

- The three configuration steps still open the same complete configuration page.
- No configuration fields were removed or duplicated.
- No new Preferences keys were introduced.
- Onboarding completion behavior was not changed.
- MQTT, AWS IoT, ABRP, GPS, CAN and OTA behavior were not changed.
