# SPR-0004B.9-REV2 Validation

## Build matrix

Compile all four normal firmware environments:

- ESP32-WROOM MQTT
- ESP32-WROOM AWS
- LilyGO T-A7670 MQTT
- LilyGO T-A7670 AWS

## Hardware validation

### Existing routes

1. Open the WebUI.
2. Verify onboarding/config/status pages still work.
3. Verify OTA page still opens.
4. Verify the displayed firmware version is REV2.

### Favicon

Open the WebUI in a browser. A request for `/favicon.ico` must return HTTP 204 and must not produce a 404 log.

### Unknown route

Open, for example:

```text
http://<device-ip>/this-route-does-not-exist
```

Expected serial output:

```text
[HTTP] 404 GET /this-route-does-not-exist
```

Expected HTTP status: `404`

Expected JSON body:

```json
{
  "success": false,
  "status": 404,
  "error": "Not Found",
  "method": "GET",
  "path": "/this-route-does-not-exist"
}
```

### Regression check

- configuration survives firmware update
- MQTT/AWS behaviour unchanged
- CAN and GPS behaviour unchanged
- no reboot, watchdog or exception caused by unknown HTTP requests
