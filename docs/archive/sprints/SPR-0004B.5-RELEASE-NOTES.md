# SPR-0004B.5 Release Notes

SPR-0004B.5 adds the Multi CAN Profile Foundation to both supported firmware variants.

The existing Microlino Display-CAN decoder remains the default and retains its current telemetry behaviour. A Microlino Standard-CAN profile is now selectable and persistent, but deliberately contains no guessed CAN definitions. Its purpose is to receive official PIDs later without another architecture refactor.

The active profile is visible in local configuration and diagnostics. MQTT topics, AWS infrastructure, dashboard behaviour, ABRP and OTA are unchanged.
