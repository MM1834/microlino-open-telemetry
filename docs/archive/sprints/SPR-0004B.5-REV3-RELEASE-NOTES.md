# SPR-0004B.5 Rev.3 – Release Notes

Rev.3 completes the GPS visibility and sprint-based versioning requested after Rev.2 validation.

## Changes

- Firmware identifier updated to `SPR-0004B.5R3-MQTT` or `SPR-0004B.5R3-AWS`.
- ESP32 System Health now reports GPS UART start, NMEA reception, fix state, coordinates, satellites, HDOP, fix age and GPS UTC.
- ESP32 adds `/api/gps` with the complete shared `MotGps` status JSON.
- Optional GPS floating-point values are serialized as JSON `null` instead of an invalid `nan` token.
- LilyGO GPS card is renamed and documented as **GPS Status & Location**. It continues to use `/api/lilygo/gps` and the same shared `MotGps` fields.

## Scope

This is a focused Rev.3 patch against the uploaded Rev.2 repository. It does not redesign transport selection or add simultaneous AWS and legacy MQTT operation.
