# SPR-0004B.7 Rev.3 — Validation

Clean both environments once because the shared MotGps library changed.

```bash
cd firmware/esp32-wroom
pio run -e esp32dev-aws -t clean
pio run -e esp32dev-aws
```

```bash
cd firmware/lilygo-t-a7670
pio run -e T-A7670X-AWS -t clean
```

```bash
pio run -e lilygo-t-a7670
```
