# SPR-0004B.6 Release Notes

## Added

- Shared onboarding step and capability model.
- First-run onboarding entry page on ESP32-WROOM and LilyGO.
- Seven-step progress/status foundation.
- Persistent onboarding completion state.
- Onboarding status, complete and restart endpoints.

## Improved

- Correct board name is now selected per build.
- LilyGO `main.cpp` is formatted and structured for maintainability.
- Removed the ineffective `setup;` statement.
- Firmware version advanced to SPR-0004B.6.

## Compatibility

Existing configuration remains authoritative and is not duplicated by the wizard. Restarting onboarding does not erase configuration. Factory Reset clears both configuration and onboarding completion state.
