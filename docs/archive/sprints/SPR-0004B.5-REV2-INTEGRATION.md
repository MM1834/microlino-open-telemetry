# SPR-0004B.5 Rev.2 – Integration

## Prerequisite

Apply this revision only after SPR-0004B.5 and SPR-0004B.5 Rev.1.

## Apply patch

From the repository root:

```bash
patch -p1 < SPR-0004B.5-REV2.patch
```

Validation before applying:

```bash
patch --dry-run -p1 < SPR-0004B.5-REV2.patch
```

## Build targets

ESP32-WROOM:

```bash
cd firmware/esp32-wroom
pio run -e esp32dev
pio run -e esp32dev-aws
```

LilyGO:

```bash
cd firmware/lilygo-t-a7670
pio run -e lilygo-t-a7670
pio run -e T-A7670X-AWS
```

## First test

1. Perform a complete flash erase.
2. Flash the selected target.
3. Connect to the setup AP.
4. Open `/config`.
5. Verify the Services card and CAN 1/CAN 2 presentation.
6. Save and reboot.
7. Reopen configuration and verify persistence.
