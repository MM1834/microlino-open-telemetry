# SPR-0004B.4A Integration

## 1. Branch prüfen

```bash
git checkout develop
git pull
git status
```

## 2. Paket integrieren
Kopiere den Inhalt von `repository/` über dein lokales Repository oder verwende den enthaltenen Patch-Ordner selektiv.

## 3. CloudFormation validieren und deployen

```bash
aws cloudformation validate-template \
  --template-body file://cloud/aws/foundation/template.yaml
```

Verwende danach denselben Deploy-Befehl und dieselben Parameter wie beim bestehenden Foundation-Stack. Die produktiven Cognito URLs müssen weiterhin enthalten:

```text
https://www.microlino-open-telemetry.ch/dashboard/
```

Nach dem Deployment:

```bash
aws cloudformation describe-stacks \
  --stack-name mot-dev-foundation \
  --query 'Stacks[0].Outputs[?OutputKey==`VehicleWebSocketUrl`].OutputValue' \
  --output text
```

## 4. Dashboard konfigurieren
Ergänze in der produktiven `dashboard/config.js` unter `awsBackend`:

```js
websocketUrl: "wss://API_ID.execute-api.eu-north-1.amazonaws.com/$default",
pollingIntervalMs: 5000,
heartbeatMs: 30000,
reconnectDelaysMs: [5000, 15000, 60000, 120000, 300000]
```

## 5. Dashboard veröffentlichen
Veröffentliche mindestens:

- `dashboard/index.html`
- `dashboard/css/dashboard.css`
- `dashboard/js/app.js`
- `dashboard/js/providers/aws-backend-provider.js`
- `dashboard/js/live/websocket-client.js`
- produktive `dashboard/config.js`

## 6. Erwartetes Ergebnis
Nach Login:

- Cloud: `Online`
- Live: `Verbunden`
- Live-Detail: `Abonniert: <vehicleId>`
- Fahrzeugdaten werden in 4A weiterhin über REST alle 5 Sekunden geladen.
