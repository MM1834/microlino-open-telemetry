# SPR-0004B.8-REV2 Manifest

## Purpose

REV2 completes the B.8 configuration consolidation started in REV1. It adds no end-user feature and does not change the configuration schema.

## Changes

### Shared

- Added `firmware/common/config/config_keys.h`.
- Kept one abstract `ConfigurationManager` lifecycle contract.
- Replaced manual readiness JSON concatenation with ArduinoJson serialization.

### ESP32-WROOM

- Added concrete `AppConfigurationManager`.
- Moved load, save, clear, normalization, validation, import and export behind the manager.
- Startup, Wizard/WebUI, REST import/export and factory reset now call the manager.
- Removed the former free configuration lifecycle functions.

### LilyGO T-A7670

- Added concrete `LilygoConfigurationManager`.
- Moved load, save, clear, normalization, validation, import and export behind the manager.
- Startup, Wizard/WebUI, REST import/export and factory reset now call the manager.
- Removed the former free configuration lifecycle functions.

## Compatibility

- Preferences namespaces and stored keys are unchanged.
- REST routes are unchanged from REV1.
- JSON `schemaVersion` remains `1`.
- Existing backups remain importable.
- Omitted import fields retain their current values.
- Standalone onboarding remains the primary local configuration path.

## Package application

Apply this repository-root-relative package over:

1. the committed B.7 repository snapshot, and
2. the already integrated SPR-0004B.8-REV1 package.

No wrapper directory is included.
