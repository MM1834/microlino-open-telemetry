# SPR-0004B.5 Rev.2 – Validation matrix

Run the following on ESP32-WROOM and LilyGO.

## Configuration

- Factory reset returns to AP mode.
- AWS, MQTT and ABRP checkboxes persist independently.
- Export contains `services.aws`, `services.mqtt` and `services.abrp`.
- Import restores all three flags.
- Older config JSON without `services` still imports.

## Service behaviour

- All services off: CAN, GPS, status and WebUI continue working without connection loops.
- ABRP only: sends only when API key and token are complete.
- MQTT only: connects only when MQTT is enabled and host is configured.
- AWS only: connects only in AWS build with credentials and AWS enabled.
- GPS absent/no fix: no service fails; location remains unavailable.
- GPS valid: enabled services receive coordinates according to their existing transport implementation.

## CAN

- CAN 1 profile selection persists.
- Display CAN continues decoding known values.
- Standard CAN remains a no-output template.
- CAN 2 is visible as reserved and cannot be activated.

## Regression

- OTA remains available.
- Configuration backup/restore remains available.
- Existing MQTT topic structure remains unchanged.
- Existing AWS topic structure remains unchanged.
- Existing ABRP payload format remains unchanged.
