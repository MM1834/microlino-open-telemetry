# SPR-0004B.7 Rev.3 — Changelog

## Shared MotGps

- Replaced macro-prone enum values:
  - `DISABLED` → `GPS_DISABLED`
  - `NO_MODULE` → `GPS_NOT_DETECTED`
  - `MODULE_DETECTED` → `GPS_DETECTED`
  - `FIX_VALID` → `GPS_FIX`
- Updated state-name JSON strings accordingly.
- Bumped local library version to `0.2.1`.

## ESP32-WROOM

- Updated System Health defaults and WebUI state mappings.
- Kept the runtime distinction between UART startup, raw activity, valid NMEA,
  module detection and current GPS fix.

## LilyGO T-A7670

- Added wrapper accessors for GPS startup, detection and canonical state.
- Replaced the wizard's hard-coded `GPS: available` with live detection.
- Added `gpsState` to onboarding status.
- Changed onboarding `gps` capability from hard-coded `true` to runtime detection.

## Detection rule

A module is detected only after TinyGPSPlus has accepted at least one
checksum-valid NMEA sentence. Raw UART noise is not sufficient.
