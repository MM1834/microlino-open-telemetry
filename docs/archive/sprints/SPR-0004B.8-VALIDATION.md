## Hardware/build validation required

PlatformIO is not installed in the packaging environment. Run these builds locally:

```bash
cd firmware/esp32-wroom
pio run -e esp32dev
pio run -e esp32dev-aws

cd ../lilygo-t-a7670
pio run -e lilygo-t-a7670
pio run -e T-A7670X-AWS
```

Then validate:

1. Existing settings survive OTA.
2. Wizard and normal configuration pages still save correctly.
3. `GET /api/config` and old `GET /api/config/export` return valid JSON.
4. Export then import restores settings.
5. `POST /api/config` accepts a raw JSON body.
6. `/api/readiness` has the same top-level schema on both boards.
7. Factory reset returns to AP onboarding.
8. MQTT, AWS, ABRP, GPS, CAN, and OTA regressions are absent.
