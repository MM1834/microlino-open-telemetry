# SPR-0004B.9-REV2 Changelog

## Added

- Shared HTTP fallback handler for both supported boards.
- Diagnostic log containing HTTP method and requested URI.
- Structured JSON response for unknown routes.
- Explicit favicon response to suppress harmless browser-generated 404 requests.

## Changed

- ESP32-WROOM now uses the shared fallback implementation instead of its local plain-text handler.
- LilyGO T-A7670 now has the same fallback behaviour as ESP32-WROOM.
- Firmware-visible version updated from REV1 to REV2.

## Not changed

- CAN acquisition and decoding
- GPS
- MQTT
- AWS IoT
- ABRP
- configuration schema
- OTA implementation
