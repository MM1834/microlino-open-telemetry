# SPR-0004B.7 Rev.2 — Changelog

## Fixed

- Completed the `MotGps` public API so ESP32-WROOM code no longer calls a missing `detected()` method.
- Added a canonical `MotGpsState` enum.
- Changed the ESP32 wrapper to obtain detection from the complete shared status object.
- Increased the local `MotGps` library version to `0.2.0` to reduce stale PlatformIO dependency-cache issues.

## GPS state model

The shared library now distinguishes:

- `DISABLED`
- `NO_MODULE`
- `MODULE_DETECTED`
- `FIX_VALID`

Raw UART bytes alone do not count as module detection. Detection requires at least one checksum-valid NMEA sentence accepted by TinyGPSPlus.

## WebUI and API

- Wizard hardware detection uses the canonical GPS state.
- Wizard validation shows `GPS state`, UART startup, module detection, NMEA reception and fix status.
- System Health returns the same state.
- `/api/gps` includes a `state` property.
- `/api/system-health` includes `gps.state`.
- `/api/onboarding` continues to expose the detected capability using the corrected runtime result.

## Intentionally unchanged

- LilyGO code and WebUI
- AWS, MQTT, ABRP, CAN and WiFi logic
- PlatformIO environment names
- Legacy firmware variants
- Onboarding AWS page and final documentation
