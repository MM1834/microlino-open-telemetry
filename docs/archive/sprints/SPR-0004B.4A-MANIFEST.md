# SPR-0004B.4A Manifest

## Ziel
Live-Infrastruktur für das Web-Dashboard, ohne Telemetrie-Fan-out.

## Enthalten
- API Gateway WebSocket API
- Cognito Access-Token-Prüfung beim `$connect`
- DynamoDB-Tabelle für aktive Verbindungen und Fahrzeug-Abonnements
- Routen `$connect`, `$disconnect`, `subscribe`, `ping`, `$default`
- Server-Antworten `subscribed` und `pong`
- Dashboard-WebSocket-Client
- Heartbeat alle 30 Sekunden
- Reconnect-Sequenz 5 / 15 / 60 / 120 / 300 Sekunden
- Separater Live-Status im Dashboard
- Fahrzeugwechsel aktualisiert das WebSocket-Abonnement
- Bestehendes REST-Polling bleibt mit 5 Sekunden aktiv

## Bewusst nicht enthalten
- Telemetrie-Fan-out aus StateIngest
- SOC-/Lade-/Batterie-Live-Events
- Firmware-Änderungen
- OTA
- Mobile App
