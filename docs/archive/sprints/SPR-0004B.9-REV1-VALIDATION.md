# SPR-0004B.9 REV1 validation

## Build

```bash
cd firmware/esp32-wroom
pio run -e esp32dev
pio run -e esp32dev-aws

cd ../lilygo-t-a7670
pio run -e lilygo-t-a7670
pio run -e T-A7670X-AWS
```

## Runtime checks

For each flashed target verify:

1. Boot log shows the expected `SPR-0004B.9-REV1-*` version.
2. Main WebUI shows the same version.
3. Configuration export contains the same `firmware` value.
4. Status/health API contains the same version.
5. MQTT system firmware version contains the same version after publishing.
6. Existing configuration remains preserved after OTA/update.

Expected values:

| Environment | Version |
|---|---|
| `esp32dev` | `SPR-0004B.9-REV1-MQTT` |
| `esp32dev-aws` | `SPR-0004B.9-REV1-AWS` |
| `lilygo-t-a7670` | `SPR-0004B.9-REV1-MQTT` |
| `T-A7670X-AWS` | `SPR-0004B.9-REV1-AWS` |
