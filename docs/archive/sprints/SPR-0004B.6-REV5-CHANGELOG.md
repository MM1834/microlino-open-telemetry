# SPR-0004B.6 Rev.5 — Changelog

## Modified

- `firmware/esp32-wroom/src/web/web_ui.cpp`

- Seven-step onboarding navigation
- Welcome, hardware, connectivity, vehicle, services, validation and finish pages
- Back, Next, Skip and Restart actions
- Progress indicator

- Live validation using existing diagnostics APIs
- Persistent completion through the existing onboarding flag
- Automatic launch remains active until onboarding is completed
- `/api/onboarding` now reports step name and step number

- Preferences keys
- MQTT, AWS and ABRP service lifecycle
- CAN acquisition and decoding
- GPS acquisition
- Existing configuration routes
