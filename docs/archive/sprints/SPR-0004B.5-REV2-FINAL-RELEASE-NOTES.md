# Release Notes

SPR-0004B.5 Rev.2 finalization aligns the two firmware branches before the onboarding sprint.

Changes:

- sprint-based firmware versions
- compile-time AWS/MQTT build variant in the visible version
- ESP32 Health Check extended with GPS module, location and UTC status
- LilyGO gains a consolidated System Health endpoint and WebUI card
- LilyGO health output consolidates network, LTE modem, GPS, CAN, MQTT and ABRP state
- validation matrix documents common and board-specific diagnostics

No telemetry payload contract or CAN decoder behavior is changed.
