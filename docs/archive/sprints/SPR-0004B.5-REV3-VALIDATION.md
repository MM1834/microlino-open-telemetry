# SPR-0004B.5 Rev.3 – Validation

## Apply

```bash
patch --dry-run -p1 < SPR-0004B.5-REV3.patch
patch -p1 < SPR-0004B.5-REV3.patch
```

## Build matrix

```bash
cd firmware/esp32-wroom
pio run -e esp32dev
pio run -e esp32dev-aws

cd ../lilygo-t-a7670
pio run -e lilygo-t-a7670
pio run -e T-A7670X-AWS
```

Use the actual LilyGO environment names from `platformio.ini` if they differ.

## ESP32 checks

1. Confirm the page shows `SPR-0004B.5R3-MQTT` or `SPR-0004B.5R3-AWS`.
2. Open **System Health** and run the test.
3. With no GPS connected, confirm `GPS UART: STARTED`, `GPS data: WAITING`, `GPS fix: NO FIX`, and location `--`.
4. With GPS connected but indoors, confirm NMEA reception can change to `RECEIVED` while fix remains `NO FIX`.
5. With a valid fix, confirm coordinates, satellites, HDOP, fix age and GPS UTC are displayed.
6. Open `/api/gps` and verify valid JSON, including JSON `null` for unavailable numeric values.

## LilyGO checks

1. Confirm the version is R3 with the correct build variant.
2. Confirm the **GPS Status & Location** card is present.
3. Verify `/api/lilygo/gps` reports `started`, `seen`, `valid`, coordinates, satellites, HDOP, age and UTC.
4. Repeat no-data, NMEA-without-fix and valid-fix scenarios where practical.

## Regression checks

- CAN telemetry remains unchanged.
- Service selections persist after reboot.
- Factory Reset still clears configuration and returns to AP mode.
- MQTT/AWS and ABRP behaviour remains unchanged from Rev.2.
