# LG-S3-001 — T-SIM7670G-S3 firmware pilot

> **Status:** Firmware prepared and build-qualified; physical acceptance open

## Objective

Add the 16 MB ESP32-S3/SIM7670G Standard board without forking the established
LilyGO application behavior or weakening telemetry, vehicle isolation, portal
security, MQTT TLS, WiFi preference or LTE fallback.

## Implemented scope

- isolated board pin map for modem, integrated GNSS, native TWAI CAN1 and MCP2515 CAN2;
- dedicated N16R2 PlatformIO target and dual-slot 16 MB OTA partition table;
- SIM7670 modem-filesystem upload path for AWS CA, client certificate and key;
- delayed integrated-GNSS setup retry while modem initialization completes;
- full standard feature set, including opt-in 256 KiB offline cache and WiFi-only ABRP;
- S3-aware OTA image guard and a fresh default device/vehicle identity.

## Evidence and risks

The ESP32-S3 target and the existing four-megabyte A7670 target both compile.
This establishes source and size compatibility, not hardware acceptance. The
highest residual risk is modem TLS filesystem behavior under real credentials,
followed by GNSS UART configuration and shared modem recovery. Camera/SD use is
intentionally excluded because their pins are allocated to CAN.

## Physical gates

Follow the acceptance list in
[the hardware record](../../hardware/lilygo-t-sim7670g-s3.md). Keep the existing
A7670 pilot powered off while the new identity is being provisioned if any cloud
credentials or identifiers are temporarily copied during setup.
