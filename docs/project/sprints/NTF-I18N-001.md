# NTF-I18N-001 — Multilingual Notifications

**Status:** Completed — backend deployed and technical acceptance passed

**Started:** 2026-09-11

## Objective

Send MOT-generated email and SMS notifications in a user-selected language independently
of the portal language. German remains the safe default for every existing and
new user/vehicle preference.

## Contract

- `notificationLanguage` accepts only `de`, `en`, `fr` or `it`;
- missing, legacy or unknown stored values resolve to `de`;
- changing the language does not change the destination, SNS subscription or
  confirmation state;
- SOC-target, charging-stop, charging-summary, journey-summary and daily-summary
  email subject/body use one central template module;
- SOC-target and charging-stop SMS use the same language preference, remain
  ASCII-only and at most one 160-character segment;
- SMS delivery remains restricted to verified and approved `+41`/`+49`
  destinations; all existing spend, rate and kill-switch gates remain unchanged;
- the AWS-managed SNS confirmation email remains unchanged;
- the setting is stored per authenticated user/vehicle preference.

## Implementation state

The preference API exposes and validates the additive field. Settings provides a
four-language selector under Notifications and loads/saves it with the selected
vehicle. The Notification Lambda uses centralized plain-text templates with
localized labels, decimal formatting, timeout notes and energy-source labels.
The two supported SMS event types use compact ASCII-only localized templates.
No table migration is required: all records without the field are German by
contract, so current users retain today's behaviour immediately.
