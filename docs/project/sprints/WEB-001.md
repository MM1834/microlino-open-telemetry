# WEB-001 — Public Project Landing Page

> **Status:** Complete; deployed and maintainer-validated
>
> **Date:** 2026-08-04

## Objective

Replace the manually maintained project homepage with a responsive, versioned and
reviewable static landing page that communicates the current MOT architecture,
portal experience, onboarding flow and validated pilot status.

## Scope

- maintain the public root website in the repository;
- reuse project-owned branding, vector vehicle artwork and portal screenshots;
- link to the authenticated portal without coupling landing-page code to portal
  authentication or runtime configuration;
- distinguish AWS IoT, local WebUI and direct ABRP paths;
- support desktop, tablet and mobile layouts;
- provide accessible semantic HTML and keyboard navigation;
- define a bounded publication and rollback procedure.

## Out of scope

- automatic deployment to the public host;
- FileZilla/FTPS credentials or host configuration;
- changes to `/dashboard/`, `/motbeta/`, Cognito or AWS resources;
- public account self-registration;
- analytics, tracking or third-party marketing scripts;
- claims beyond current governance evidence.

## Deliverables

- `build/landing/current/index.html`;
- `build/landing/current/css/site.css`;
- self-contained landing-page image assets;
- reusable Microlino outline vector;
- public landing-page owner documentation;
- local responsive and link validation evidence.

## Acceptance gates

- page loads without external JavaScript or CDN dependencies;
- all local assets return successfully;
- `/dashboard/` remains the primary portal destination;
- layout has no horizontal overflow at 390, 768 and 1440 CSS pixels;
- document has one `h1`, semantic landmarks and a keyboard-visible skip link;
- no secrets, cloud configuration or personal data are included;
- architecture and status claims match current governance;
- public deployment remains separately authorized and rollbackable.

## Validation evidence

On 2026-08-04:

- the landing page loaded through a local HTTP server with its stylesheet, logo,
  Microlino vector and dashboard screenshot;
- the browser reported no console warnings or errors;
- all local images completed with non-zero natural dimensions;
- all in-page navigation targets resolved;
- 1440 px, 768 px and 390 px viewport checks had document widths exactly equal to
  the corresponding viewport width, with no horizontal overflow;
- the rendered document contained exactly one `h1` and exposed header, navigation,
  main and footer landmarks;
- XML validation passed for the reusable Microlino vector and both poster SVGs;
- `git diff --check` passed.

On 2026-08-05 the maintainer deployed the landing page manually through FileZilla
and confirmed successful hosted operation on desktop and smartphone. WEB-001 is
complete. The existing manual FTPS and backup boundary remains the publication
model for future landing-page updates.
