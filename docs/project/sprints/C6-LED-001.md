# C6-LED-001 - N16 status LED

> **Status:** Complete
>
> **Completed:** 2026-09-16
>
> **Release:** `C6-001-REV29-AWS`

## Objective

Use the nanoESP32-C6-N16 onboard WS2812 RGB LED on GPIO8 as a low-brightness,
non-blocking indication of adapter connectivity without changing the XIAO pin
mapping or consuming an additional external GPIO.

## Delivered behaviour

- white gentle pulse while onboarding is incomplete;
- magenta gentle pulse while WiFi is configured but not connected;
- blue while WiFi is connected without AWS IoT or local MQTT;
- green while AWS IoT is connected;
- cyan while local MQTT alone is connected;
- green with a small blue component while AWS IoT and local MQTT are connected;
- red gentle pulse after a detected Dual-CAN startup failure.

The LED update runs cooperatively every 40 ms, uses no blocking delay and limits
the maximum channel value to 16 of 255. The complete GPIO8 implementation is
excluded from the XIAO build with `MOT_XIAO_BOARD`.

## Validation

- focused C6 production-hardening contracts pass, including GPIO8 ownership,
  non-blocking operation, XIAO exclusion and runtime connection-state inputs;
- `nanoesp32c6-n16` and `xiao-esp32c6` compile successfully;
- REV26 was flashed to the physical N16 with image-hash verification;
- boot, WiFi, AWS IoT and local MQTT indications passed physical acceptance on
  2026-09-16;
- the red startup-error path was not physically provoked because doing so would
  require an artificial CAN initialization failure. Its implementation remains
  covered by the focused source contract.

## Closure

C6-LED-001 is complete. A separate external Power-On LED remains a hardware
assembly option and is not part of this firmware sprint.

## REV29 remote-diagnostic refinement

Field observation showed that the equal red/green low-brightness pulse intended
as yellow was perceived as green by multiple observers and was therefore
ambiguous with the connected state. REV29 removes that signal, distinguishes
incomplete onboarding with a white pulse from a configured WiFi outage with a
magenta pulse, and retains all accepted connected/error indications. Source
contracts and N16/XIAO builds pass. Physical testing on 2026-09-17 accepted the
new white incomplete-onboarding and magenta configured-WiFi-offline indications.
The exact encrypted N16 REV29 image is active in the controlled WebFlash catalog,
with four audited 48-hour user grants. The REV29 refinement is complete.
