# Dashboard Overview

![Desktop Home](../assets/images/dashboard/desktop-home.png)

The dashboard provides current and live telemetry through the configured provider.
For the AWS backend it can also render authorized SOC, charging, plugged and Speed history for
24 hours, 7 days and 30 days. The server-side history path is implemented but not
yet deployed; legacy MQTT retains browser-local history as a fallback.

## Main views
- Home
- Battery
- Vehicle
- Charging
- Temperatures
- Cells
- Location
