# Firmware versioning

`firmware/common/system/version.h` is the single source of truth for firmware-visible version metadata.

## Required update rule

Every revision that changes firmware must update:

- `MOT_SPRINT`
- `MOT_REVISION`
- the two `MOT_VERSION` values generated for MQTT and AWS variants

No board-specific header may define its own `MOT_NAME`, `MOT_VERSION`, `MOT_BUILD_VARIANT`, `MOT_SPRINT`, or `MOT_BOARD`.

## Consumers

The central values are used by:

- boot log
- WebUI and OTA page
- configuration export
- status and health APIs
- telemetry and retained MQTT device information

`MOT_BUILD_DATE` and `MOT_BUILD_TIME` are compiler-provided build metadata and are not release identifiers.

## B.9 REV1

- Sprint: `SPR-0004B.9`
- Revision: `REV1`
- MQTT version: `SPR-0004B.9-REV1-MQTT`
- AWS version: `SPR-0004B.9-REV1-AWS`
