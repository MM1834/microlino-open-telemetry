# Waveshare ESP32-S3-Touch-LCD-1.85C V2 board support

The files in `src/` are derived from Waveshare's official Arduino example
for the ESP32-S3-Touch-LCD-1.85C V2, commit
`8ead4a96bf3a278fc4ebd8ef4768657e17fa2880`.

Source: https://github.com/waveshareteam/ESP32-S3-Touch-LCD-1.85C

The upstream files are licensed under Apache License 2.0. They are kept in a
target-specific PlatformIO library so the existing 1.28-inch C6 target remains
independent.
