# SPR-0004B.7 Rev.2 — Validation

## Clean build

Because the shared local library API and version changed, clean the environment once:

```bash
cd firmware/esp32-wroom
pio run -e esp32dev-aws -t clean
pio run -e esp32dev-aws
```

Expected: no error concerning `MotGps::detected()` or another missing GPS member.

## Test A — No GPS module connected

Expected after boot and validation:

```text
GPS state : NO_MODULE
GPS UART  : STARTED
GPS module: NOT DETECTED
GPS NMEA  : WAITING
GPS fix   : N/A
```

`/api/gps` should contain:

```json
{
  "started": true,
  "detected": false,
  "valid": false,
  "state": "NO_MODULE"
}
```

Electrical noise may set `seen` to true, but must not change the state to `MODULE_DETECTED`.

## Test B — GPS connected, no satellite fix

After valid NMEA data has arrived:

```text
GPS state : MODULE_DETECTED
GPS UART  : STARTED
GPS module: DETECTED
GPS NMEA  : VALID
GPS fix   : NO FIX
```

## Test C — GPS connected with a current fix

Expected:

```text
GPS state : FIX_VALID
GPS module: DETECTED
GPS fix   : VALID
```
