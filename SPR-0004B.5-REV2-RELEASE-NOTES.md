# SPR-0004B.5 Rev.2 – Release notes

## Added

- Explicit optional service switches for AWS IoT, MQTT and ABRP.
- Backward-compatible service flag migration.
- `services` section in configuration export/import.
- CAN channel-oriented WebUI.
- Visible CAN 2 reserved placeholder on both current hardware targets.

## Changed

- MQTT no longer becomes operational solely because a host exists after the new service flag has been stored.
- ABRP now requires both explicit enablement and complete credentials.
- AWS can be disabled locally in AWS-enabled builds.

## Not implemented

- A physical second CAN channel.
- ESP32-C6 support.
- External CAN controllers such as MCP2515.
- Changes to decoder output, MQTT topics, AWS topics or ABRP protocol.

## Build validation

The patch is structurally validated against the supplied Rev.1 state. PlatformIO compilation must be performed by the integrator because PlatformIO is not installed in the generation environment.
